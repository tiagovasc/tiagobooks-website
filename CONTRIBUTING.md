# Contributing

Bug reports and focused improvements are welcome. Describe the page, expected behavior, actual behavior and steps to reproduce. Remove passwords, tokens, personal catalogue exports and private information from reports and screenshots.

For code changes, follow the README setup, keep the shared header consistent across sections, preserve existing content and URLs, and run the public-source check, build and tests. Use synthetic records for tests. Please discuss large feature or content changes before preparing a pull request.

Do not include generated `dist/`, dependencies, `.env`, `.local/`, private drafts or backup files. Use your GitHub noreply address if you do not want your email address in public commit history. Check the staged diff and commit identity before pushing; CI runs after GitHub has already received a commit.

Read [RIGHTS.md](RIGHTS.md) before reusing writing, artwork or book-cover assets.
